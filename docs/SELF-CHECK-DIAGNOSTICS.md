# 一键自检与脱敏诊断

设置 → 自检与诊断 → 一键自检。分别查看中转认证、收件箱同步、主机心跳、Codex 适配器与采集、Claude hook 观测及启动对账。每项给出固定原因与下一步建议。测试推送和测试原调用回复有独立入口。

## 状态与证据

| 检查 | 能确认的事实 | 不能据此确认 |
| --- | --- | --- |
| 中转与认证 | 本次设备鉴权后的诊断 API 返回 | 主机在线、采集正常 |
| 收件箱同步 | 本次正常收件箱 API 返回 | APNs 到达、答案接收 |
| 主机 | 中转最近 30 秒收到心跳 | 原生适配器与 hook 正常 |
| Codex 适配器／采集 | 初始化完成、同轮 loaded-thread 与分页目录扫描成功 | 所有启动入口均受支持、没有产生过的题能被采集 |
| Claude hook | 最近观察到合法且在采集范围内的事件 | 未观察到事件时推断 hook 已安装或损坏 |
| 推送 | 排队、APNs 接受、此 iPhone 观察到通知分别记录 | 原调用收到答案 |
| 已提交 | 绑定本次 request／response 的 relay 持久回执 | 原调用收到答案 |
| 原调用已接收 | 现有原生仲裁来源证明与原调用结构化输出一致 | 后续执行已经继续 |
| 任务已继续 | 接收之后的同一执行链原生进展 | 其他引擎或启动入口同样可用 |

只有新鲜诊断快照中的心跳超时才报告主机链路异常；无法访问中转或快照过期时，下游状态显示未确认。界面与分享重新计算观测时效，不把过期通过状态保留为当前通过。已取得的原调用接收事实独立保留。

## 两种测试

**测试推送**由 relay 创建固定、无敏感内容的诊断题，只给发起设备排队。即使没有支持原生来源证明的 host，也可以独立测试这段通知链路。APNs 仅接受时保持手机到达未确认；只有系统通知列表或实际 APNs delegate 回调观察到本次请求才确认到达。点击测试通知定位对应诊断页。未配置 APNs 或未注册设备时明确提示。

**测试原调用回复闭环**当前自动支持启用了 `native/codex` 来源扩展的 Codex app-server。host 创建独立的私有测试目录与全新原生 thread；线程级模型配置指向只监听 loopback 的固定 Responses 提供者。提供者只生成固定 `request_user_input` 和继续消息，不调用外部模型，不执行命令，不读取／转发业务题目。后续响应保留短暂间隔，便于独立观察已接收与已继续。

原生测试题沿现有采集、版本绑定、答案提交、一次派发、原生仲裁和原输出核对流程运行。用户在诊断页选择固定测试答案。提供者自身不签发 received／continued 证明。未扩展 Codex、Claude 自动原生测试保持未支持，不伪造替代回执，不放宽正常目录和会话采集范围。

作业有效期 180 秒，同一主机每种模式最多一个活动作业。设备持有作业归属；host 原子领取一次，重启不再次启动已领取的原生测试。丢失创建响应复用原作业 ID；推送题创建中断可用同一 ID 修复，并保留原期限。断网后只读核对；仍待答时仅允许复用已保存的同一答案重试。测试题不进入正常 App／Widget 待办，不给其他设备回填测试推送。

## 分享白名单

“分享脱敏诊断”只编码独立模型：schema 版本、应用版本数字组件、系统主版本、报告内主机序号、固定阶段／状态／原因码、距观测的秒数。未知服务端字符串不能透传。

不包含凭据、配对码、APNs token、URL／IP／域名、主机／设备／请求／会话标识、原生证明、项目或本地文件路径、题目／答案正文、任意错误文本、日志。页面上的已授权主机身份也不进入分享模型。原始本地测试记录继续位于忽略目录。

## 本地验证与交付边界

本轮 Rust 全套 149 项通过、3 项条件忽略；iOS 单元 160 项通过、6 项条件跳过；实际模拟器诊断页点选到真实原生引擎的 UI 闭环 1 项通过，截图已检查。独立审查的 5 项恢复／状态问题均已复现并修复。

Rust 回归覆盖鉴权、设备归属、幂等／期限、一次领取、推送创建中断恢复、loaded-thread 发现失败、诊断题隔离及通知与接收独立。Swift 回归覆盖白名单污染、原答案绑定、陈旧快照、切换中转、重叠测试与提交前失败恢复。

隔离真实来源扩展 Codex 已通过：本次答案原调用已接收 → 尚未继续 → 同一调用继续；正常待办为空，未连接外部模型。该验证没有配置 APNs，不能代替真实 iPhone 通知送达验收。

测试入口（输出目录必须是新的本地临时／忽略目录）：

```sh
python3 native/codex/qualify_diagnostics.py \
  --binary target/debug/agentinbox \
  --native-binary .superpowers/native-reply/upstream/codex-rs/target/debug/codex-app-server \
  --output .superpowers/diagnostic-native-qualification
```

脚本只使用独立临时配置、人工测试凭据与本地进程，退出时停止测试子进程。`--serve-app-fixture` 可供显式启用的模拟器 UI 测试使用；普通测试没有此环境时跳过。生产 relay／正式 host 升级、真实 iPhone 安装与 APNs 现场验收须另行完成，本项不能仅凭本地通过标为全部验收完成。
