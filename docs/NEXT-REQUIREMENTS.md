# 下一版需求

本文描述 AgentInbox 首版基础上的下一轮需求与验收目标，不代表功能均已实现；现有能力与验收边界以 [STATUS.md](STATUS.md) 为准。继续采用轻量 Go／Rust 原生 daemon，目标机器无需 Node／Python 等语言运行时；不限定 Agent 启动入口，保留正常 CLI 与 Mac App 使用习惯。简单选项在主屏 Widget 操作，文本回复进入 App。

## 1. 只读 API 关联 Tailscale＋复用 iPhone VPN

2026-10-21 用户在实机核对 Screens 首次关联页面后，确认此前记忆有误，并明确选择“按现有方案继续”，自行在手机填写凭据做真机验证。采用 Tailnet ID＋仅 Devices → Core → Read 的 OAuth Client Secret 关联，自动获取设备目录。iPhone 独立 Tailscale App 继续提供 VPN；AgentInbox 不创建额外节点、不恢复内置 TailscaleKit、不要求快捷指令。

凭据保存在此 iPhone 的 App 私有 Keychain，不进入聊天、设备缓存、Widget、daemon 或 relay。客户端使用 client credentials 换取短期设备只读 token；管理控制台可另行打开，但不充当设备 API 授权。此前免填凭据的网页授权要求由本次决定替代，实验记录保留在 [核查文档](TAILSCALE-WEB-AUTH-INVESTIGATION.md)。

设备列表每行只显示 Tailscale 域名与 IPv4／IPv6；主机名、系统、Tailscale 版本、控制面状态及 daemon／应用认证状态进入详情查看。Tailnet＋稳定设备 ID 去重，改名、IP 变化与账号切换不混入旧设备。授权失败、取消或网络失败保留原 AgentInbox 配对，VPN 断开／恢复后重新访问并对账。真实 iPhone 的“打开关联页 → 填写只读凭据 → 自动返回设备列表 → 重启恢复／刷新”及私网访问验证是完成门槛，现有单元测试和安装不代替该验收。

当前状态与证据见 [FEATURE1-TAILSCALE.md](FEATURE1-TAILSCALE.md)。

打开 App 或从后台返回时检查本机 Tailscale VPN 连接迹象；未检测到时提示打开 iPhone 的 Tailscale App 登录并连接。原目标为确认后直接唤起 Tailscale、未安装时打开商店；2026-10-22 真机发现裸深链接触发设备签名错误，直接唤起目标暂未满足，当前替代为明确标注“前往 App Store”，在那里打开已安装的 App 或安装。提示可暂时关闭，连接返回后重新检测，兼容深浅色；不自动连接或修改 VPN。

设备详情明确显示 Tailscale 域名，并提供“设置为中继服务器”：使用该域名及当前中继的协议、端口，先验证中继 API 和现有应用配对，通过后才保存；失败或取消保留原地址。此操作独立于 8788 主机发现，不自动部署服务；切换后 App 与 Widget 丢弃原中继缓存及在途结果。

## 2. 回复可靠闭环

2026-10-22：本轮已实现分步回执协议、持久恢复与防重投、App/Widget 状态解释，并完成本地验证；当前原生接口的胜者来源仍不能确证，保守显示“原答案匹配，来源未确认”，不补造接收/继续证明。尚未计为本项完整验收通过，详见 [实现、验证与剩余验收](REPLY-RELIABILITY.md)。

用户应能确认答案是否真正回到原任务。界面分别展示“已提交”“原调用已接收”“任务已继续运行”，每一步只依据对应的精确回执推进；请求绑定机器、引擎实例、原会话／轮次／调用、内容版本与期限，防止重复、过期及本地与手机竞态造成错答。断线或重启后应恢复待办与提交状态并对账，结果未知时明确提示，不盲目重试。验收：重复提交、旧题回复、竞答及恢复场景均不串题或重复派发，无原调用证明不显示接收，无继续运行证明不显示已继续。

## 3. 决策上下文

用户应能在手机上判断自己正在批准或回答什么。决策卡展示机器、项目、任务目标、阻塞原因、原始问题／命令及影响范围；摘要用于快速浏览，必须能查看完整原文，不能替代、截断关键内容或掩盖未知信息。验收：仅凭准确请求详情即可辨认任务和影响，长问题与命令原文可完整查看，缺失上下文明确标示。

## 4. 主屏 Widget 待办体验

用户应能在主屏快速处理简单选择，文本与复杂问题打开 App 的准确请求页。Widget 展示待办计数、等待时长、最近同步时间和发送中反馈；提交绑定点击时的请求与选项，拒绝过期操作，并在切换下一条时防止连续点击误答新题。验收：简单选择无需打开 App，文本入口准确定位原题；旧组件内容不能回答新题，发送中和同步滞后可识别，自动切题不会沿用上一题的点击。

## 5. 一键自检与脱敏诊断

用户应能快速定位收不到题或回不去答案的原因。App 一键检查主机、适配器及采集、中转、同步、回传各段链路状态，提供测试推送与测试回复闭环，并生成可供排障的脱敏诊断。验收：测试结果区分主机离线、采集／适配器异常、中转或同步失败与原调用未接收；通知到达不等于回复闭环通过，诊断不包含凭据或原始敏感正文。

## 6. 兼容覆盖与回归

用户应能明确判断自己的使用组合是否可用。持续维护 Codex／Claude、CLI／Mac App、tmux／Herdr、Mac／Ubuntu 的支持矩阵，按实际证据标注“可回传”“仅通知”“未支持”及版本和限制，优先覆盖常用组合并在 Agent、系统和产品升级时回归。验收：常用组合有可复查的原请求回传证据或明确限制，CLI 成功不外推 Mac App，未验证组合不宣称已支持，不承诺全覆盖已经实现。

## 7. 连接生命周期

用户应在前台、App 挂起及网络变化后继续收到待办并安全回传。当前路线为复用独立 Tailscale App 提供的 VPN 连接，只读 API 仅负责设备目录，不承担 VPN 连接或后台保活；结合 APNs 通知与经鉴权的 HTTPS 中转处理通知和 Widget 回传，现有阿里云 JP 可作为中转候选，Mac／Linux 复用现有 Tailscale。内置 TailscaleKit 路线已废弃。须分别验证 VPN 可用、断开及恢复时的行为；私网 HTTPS 中转仍依赖可达的 VPN 路径，APNs 送达不证明私网 API 或答案回传可用。验收：分别记录前台、挂起、进程终止、锁屏及网络切换下的通知、Widget 回传、重连和状态对账结果；系统限制或失败应明确呈现，未通过场景不计支持。

## 范围外

本轮不包含通知降噪、静音、免打扰或分级提醒功能。
