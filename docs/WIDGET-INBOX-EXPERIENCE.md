# 主屏 Widget 待办体验

2026-10-22 实现并完成隔离模拟器验收；当晚已覆盖安装正式 iPhone App／Widget，中号主屏核心流程真机复验通过，收尾核对于 2026-10-23 完成。未升级生产 relay 或常驻 host 的程序。模拟器服务与真实手机上的隔离原生问答分别记录，不将模拟结果当作真机回传证明。

## 使用行为

- 完整可读的简短单选可以直接在主屏回答。文字、多选、长题、多题、复杂审批，以及当前尺寸无法完整显示的内容进入对应请求详情。较大辅助字号也进入 App。
- “待办”统计当前缓存中尚未提交且未过期的请求；发送中、等待回执和结果未知单独展示。等待时长从请求创建时间计算，未来时间钳制到当前时间。
- “同步”显示最近一次成功读取列表的时间。刷新失败保留该时间及缓存，显示滞后和连接提示；生成组件画面时，数据超过五分钟也按滞后显示。组件仍受系统刷新调度影响；系统尚未更新画面时，可根据最近同步时间判断缓存新鲜度。
- 第一次显示的简单题可直接回答。题目变化后自动展示新题并收起选项，先点右上角“回答此题”再选择答案。展开入口与答案区域分离；展开动作只启用选项，不提交答案。
- 发送期间有系统交互等待反馈及“正在发送…”状态；此时不能展开另一题。得到提交回执后等待独立的原调用接收及继续运行证明，不将提交视为任务已经继续。
- 若进程在发送期间终止，超过 45 秒后保守显示结果未知。未知结果进入 App 核对，不自动重投。网络校验阶段失败、未保存答案时，可以明确展开后重试。
- 固定在小组件的请求仍保持固定，不因其他待办出现而跳到另一题；设置中的“显示最新待决请求”解除固定。

## 防串题边界

每个答案按钮捕获展示代次、请求 ID、版本、完整内容指纹、选项、回复编号、中继连接与配对代次。指纹包含题面、全部选项、上下文、期限和原调用绑定，排除状态及回执等可变字段。旧组件不会在执行时重新挑选当前题。

App Group 内的文件锁与原子状态文件保护点击认领；题目切换、展开及提交会更换展示代次。重复点击、相反选项、旧展开按钮及旧连接操作在网络发送前被拒绝。发送前还从中继读取原题，重新核对完整指纹及可回答状态，再沿用既有的持久原答案记录和服务端防重投链路。

本地发送状态独立于列表缓存；旧的待答列表不能重新启用已认领题目的答案。缓存中的原生终态不会被本地发送推断覆盖。Intent 不再用发送前捕获的整份缓存覆盖后来的 App 刷新。状态文件损坏或无法读取时关闭直接回答入口，并提示进入 App。

## 验证

- iOS 单元测试执行 156 项，6 项因需要特定外部环境跳过，0 失败。新增覆盖同版本内容变化、重复及相反选项、切题和返回旧题、过期、未知结果、重启恢复、配对隔离、损坏状态及多行文本显示限制。
- App UI 回归 10 项通过，覆盖决策上下文、原文、回复状态、文字和多选、机器及设置入口。
- 小号、中号和大号 Widget 的实际模拟器主屏流程均通过：第一题双击只提交一次；新题收起选项，展开入口位于旧答案区域上方；在旧答案位置继续点击也不产生第二题答案；明确展开并回答后，第二份答案只绑定第二题；文字入口打开文字原题的 App 详情。小号在选项收起时将刷新按钮移到底部，保留完整待办计数。
- 同一次主屏测试严格断言发送中反馈存在，检查两份答案的请求及选项，并验证同步失败后保留最近成功同步时间。截图经查看确认布局和状态可辨；原始截图及测试记录仅保留本地。

## 复验方式

`ios/Tools/widget-fixture-server.py` 是可选的回环模拟服务，使用明确的公开人工测试密钥，不连接任何 Agent。运行时必须指定本地输出目录；端口默认由系统分配，输出目录生成 `probe.json`。不要将该测试密钥配置到真实服务。

为专用模拟器的测试运行器设置 `AGENTINBOX_WIDGET_EXPERIENCE_FIXTURE=1` 与 `AGENTINBOX_WIDGET_PROBE_CONFIG_FILE`，指向生成的配置，运行 `WidgetSurfaceTests.testFixtureWidgetDoubleTapNextQuestionAndExactTextRoute`。测试会再次确认回环地址与人工密钥，然后重置合成服务。默认跳过，不读取真实安装配置。可额外设置 `AGENTINBOX_WIDGET_FIXTURE_FAMILY=small` 或 `large` 检查对应尺寸。
